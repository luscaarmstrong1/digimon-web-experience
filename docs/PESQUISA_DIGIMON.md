# Pesquisa e Engenharia Reversa — Franquia Digimon

## 1. Universo e Conceito Central
Digimon (Digital Monsters) originou-se como V-Pet (Virtual Pet) em 1997 e expandiu-se em animes (Adventure, Tamers, etc.), mangás, jogos eletrônicos (Digimon World, Cyber Sleuth, Next Order) e Card Game (TCG).

Diferente de franquias de monstros lineares:
- **Evoluções em Árvore/Malha:** Um Digimon Baby/Rookie pode ramificar em múltiplos Champions dependendo de cuidados, dados assimilados, atributos ou condições especiais (Jogress, Armadura, X-Antibody).
- **Atributos Canônicos:** O núcleo canônico utiliza a tríade **Vaccine**, **Data**, **Virus**, além de Free/Unknown.
- **Níveis Canônicos (Japonês / Ocidental):**
  - Baby I / Fresh
  - Baby II / In-Training
  - Child / Rookie
  - Adult / Champion
  - Perfect / Ultimate
  - Ultimate / Mega
  - Ultra / Super Ultimate / Burst Mode / Armor / Hybrid

## 2. Direção de Arte e Linguagem Visual
- **Dispositivo Central:** Digivice (interfaces com telões circulares/hexagonais, fios de dados, status de sinal e bateria).
- **Mundo Digital:** File Island, Server Continent, Dark Area, Kernel, montanhas de firewalls e oceanos de bits.
- **Circuitos e Hologramas:** Feixes de laser, grids em perspectiva isométrica/tridimensional, scanlines holográficas, fragmentação em cubos/voxels binários.

## 3. Fontes de Dados Mapeadas
- **DAPI (digi-api.com):** 1.480+ espécies com dados de níveis, atributos, tipos, campos, descrições, técnicas especiais e rotas de evolução anterior e posterior.
- **Digimon Reference Book (DRB / digimon.net):** Padrão oficial de nomes e perfis.
- **DigimonCard.io & World Digimon Card:** Dados sobre coleções, números de cartas e metadados de TCG.

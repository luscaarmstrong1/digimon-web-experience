# Modelo de Digievolução — DIGIVERSE

## 1. Topologia em Grafo Direcionado Multirrota
Ao contrário da evolução linear comum em outras franquias, o sistema Digimon baseia-se em grafos direcionados com ramificações múltiplas:

```
                  ┌─> Greymon ────────> MetalGreymon ───> WarGreymon
                  │
Agumon (Child) ───┼─> GeoGreymon ─────> RizeGreymon ────> ShineGreymon
                  │
                  └─> Tyrannomon ─────> MasterTyrannomon
```

## 2. Níveis Evolutivos Normalizados
- **Baby I (Fresh):** Estágio embrionário recém-saído do Digi-Egg (ex: Botamon).
- **Baby II (In-Training):** Formas infantis (ex: Koromon, Tsunomon).
- **Child (Rookie):** Forma básica de parceiro explorador (ex: Agumon, Gabumon, Patamon).
- **Adult (Champion):** Primeira forma de combate de grande porte (ex: Greymon, Garurumon, Angemon).
- **Perfect (Ultimate):** Forma avançada com armaduras e armamentos digitais (ex: MetalGreymon, WereGarurumon).
- **Ultimate (Mega):** Forma final lendária (ex: WarGreymon, MetalGarurumon, Omnimon/Omegamon).
- **Formas Especiais:** Armor (Digimentals), Jogress / DNA (fusão de 2 espécimes), Mode Change, X-Antibody.

## 3. Relações Canônicas vs. Simulação DIGIVERSE
- **Canônicas:** Importadas diretamente das fontes verificadas da API (`priorEvolutions` e `nextEvolutions`).
- **Simulação DIGIVERSE (DigiFarm & Batalha):** Requisitos de evolução baseados em atributos acumulados (HP, SP, ATK, DEF, INT, SPD) e nível de vínculo (Bond) conquistado em treinamento.
